🐛 TROUBLESHOOTING:

   ❌ Port 8080 in use?
      → killall node
      → npm run dev (in backend)
   
   ❌ Frontend won't load?
      → Check backend is running
      → Visit http://localhost:8080/health
      → Should show: {"ok":true}
   
   ❌ Bot gives generic responses?
      → Gemini API might be down
      → Bot still works with fallback mode!
   
   ❌ npm install fails?
      → npm cache clean --force
      → npm install again
