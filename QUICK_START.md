# 🚀 Quick Start - Binary Decoders Bargain Bot

## ⚡ Super Fast Setup (2 minutes)

### Step 1: Start Backend
```bash
cd backend
npm install
npm run dev
```

✅ Backend running at `http://localhost:8080`

### Step 2: Start Frontend
Open a **new terminal**:
```bash
cd frontend
npm install
npm run dev
```

✅ Frontend running at `http://localhost:5173`

### Step 3: Test It!
Open browser to `http://localhost:5173`

Try typing:
- **"show kurta"**
- **"add matching dupatta"**
- **"can you do ₹100 less?"**

## 🐛 Troubleshooting

**Problem**: Backend won't start  
**Solution**: Make sure you're in the `backend` folder and port 8080 is free

**Problem**: Frontend shows connection error  
**Solution**: Check backend is running on port 8080

**Problem**: Bot gives generic responses  
**Solution**: API keys are valid 22-23 Jan only. Check the date!
