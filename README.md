# 🛍️ Binary Decoders: AI Bargain Bot

**Live-Stream Bargaining Concierge for Flipkart Live**

An AI-powered bargaining bot that brings the bazaar experience online using **Gemini 2.5 Flash**.

---

## ⚡ Quick Start

### 1. Setup Backend

```bash
cd backend
npm install

# Create .env file with API keys (or use hardcoded keys in code)
# echo "GEMINI_TEXT_API_KEY=3057dfce551f4941ae42ecb8b72f5f93" > .env

# Keys are already in code, just run:
npm run dev
```

### 2. Setup Frontend

```bash
cd frontend
npm install
npm run dev
```

Visit `http://localhost:5173` and start bargaining!

---

## 🎯 Features

✅ **Natural Language Understanding** - Powered by Gemini 2.5 Flash  
✅ **Dynamic Bundle Suggestions** - "Add matching dupatta"  
✅ **Loyalty-Based Pricing** - Bronze/Silver/Gold tiers  
✅ **Inventory-Aware Discounts** - Low stock = less discount  
✅ **Conversational AI** - Culturally-aware Indian bargaining
